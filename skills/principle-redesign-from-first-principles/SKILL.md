# 第一原理から設計し直す

変更を統合するときは、既存の設計にそのまま適用しないでください。あたかもその要件が最初から存在していたかのように再設計します。

- 影響を受けるすべてのファイルを読み取り、現在の設計を理解します
- 質問してください: 「この新しい要件に基づいてこれを最初から作成するとしたら、何を構築しますか?」
- すべての参照を通じて変更を伝達します: タイプ、ドキュメント、例、理論的セクション
- 再設計全体を検討し、段階的に提供する

これは、既存の設計に変更を統合するときにオプションの値を保持する方法です。
