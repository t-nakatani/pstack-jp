# コンテキストウィンドウを守る

コンテキスト ウィンドウは有限であり、セッション内で更新できません。すべてのトークンにはそのコストに見合った価値がある必要があります。

**理由:** コンテキスト オーバーフローにより推論の品質が低下し、圧縮アーティファクトが生成され、進行が停止します。

**パターン:**
- **大きなペイロードを分離します。** 詳細な出力、スクリーンショット、および大きなドキュメントをサブエージェントにルーティングします。メイン コンテキストは生データではなく概要を取得します。
- **頻繁に使用するコンテンツをインラインに保持します。** すべての呼び出しで使用されるテンプレートと参照は、毎回読み取りが必要な別のファイルではなく、スキル ファイルに属します。
- **フェーズのサイズと範囲の上限。** フェーズごとのファイルを制限し、ターン予算を設定し、メカニズムのコストを考慮します。
