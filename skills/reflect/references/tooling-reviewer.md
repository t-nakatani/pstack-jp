## レンズ追加: エージェントの自給自足

ユーザーが手動で提供したコンテキストに、エージェントが MCP ツール (チケット トラッカー、チャット、ドキュメント、オブザーバビリティ、エラー トラッカー、ソース コントロール、分析ウェアハウス、CI、設計ツールなど) または別のスキルを介して自身で取得した可能性があるコンテキストをすべての瞬間にフラグを立てます。

そのような瞬間ごとに:
- 原則: エージェントが自動的に検索すべき内容に関する文。
- 証拠: ユーザーの手動ハンドオフ (例: チケット ID、チャット スレッド URL、可観測性トレース ID、エラー追跡イベント リンク、「これは PR #X からのものです」、設計ツール URL)。
- ルーティング: これが発生したワークフローを所有するスキル。これを拡張して関連する MCP ツールまたは兄弟スキルを呼び出し、次のエージェントがコンテキスト自体を取得できるようにします。

パターンの例:
- エージェントがチケット トラッカー MCP にクエリを実行しなかったため、ユーザーがチケット タイトルを貼り付けました。ルーティング: 関連するトリアージ スキルは、最初にチケット トラッカー MCP を呼び出す必要があります。
- ユーザーは、エージェントが可観測性 MCP を介してクエリを実行した可能性のある不安定なテストについて説明しています。ルーティング: デバッグ スキルでは可観測性 MCP について言及する必要があります。
- ユーザーは、エージェントがチャット MCP 経由で取得したチャット スレッドをリンクします。ルーティング: 関連するスキルでチャット MCP について言及する必要があります。

スキャン:
- エージェントが検出する必要があったツールの呼び出しとコマンド フラグ
- ライブラリ/フレームワークの癖 (config、lockfiles、env-var の動作、バージョン固有の注意点)
- コードを一目見ただけでは明らかではないファイルまたはパスの規則
- テスト コマンド、CI フラグ、および失敗した実行をローカルで再現する方法
- デバッグ エントリ ポイント: トレースのキャプチャ方法、ログの到達場所、どの RPC にヒットするか

## セッションで実際に使用されたスキルとツールが対象範囲

調査結果は、このトランスクリプトで呼び出されたスキル、ツール、または MCP を示している必要があります。親が開いたことのないスキルへの投機的なルーティングはカウントされません。スキルが使用されたかどうかを確認するには、トランスクリプトをスキャンして以下を確認します。

- `Read` ツールは、任意の `SKILL.md` ファイル (ワークスペース `.cursor/skills/`、ユーザーレベル `~/.cursor/skills/`、または `~/.cursor/plugins/` の下にあるプラグインがインストールされたパス) に対して呼び出します。
- `Task` スキル パスに名前を付けるプロンプト
- スキルの文書化されたコマンドと一致するツール呼び出し (Shell、Grep、MCP など)

2 つの有効な検出形状:

- 親がスキルを発動し、あなたはその体に本当の隙間を発見しました。スキルの関連セクションにルーティングします。
- スキルはカタログに表示されていましたが、役立つはずのときにトリガーされませんでした。スキルの説明を調整して、将来のエージェントがそれを認識できるようにします。 `tune description: <skill path>` としてルーティングします。

スキルが発動されなかった場合、またはミストリガー候補でもなかった場合は、そのスキルをドロップします。

見つけた永続的な学習をそれぞれリストアップします。それぞれ:
- 原則: 慣例または技術的事実の名前を 1 文で記述します。将来のエージェントがいつ適用されるかを認識できるほど具体的です。
- 証拠: トランスクリプト内の正確な瞬間 (コマンドまたはフラグを含むターン番号または短い引用符)。
- ルーティング: 最も関連性の高い既存のスキル (トランスクリプトに表示される `SKILL.md` パスを指定します)、またはスキルがトリガーされるはずだったがトリガーされなかった場合の `tune description: <skill path>`、または「新しいスキル: <kebab-name>」。

些細なこと (タイプミス、再試行) はスキップしてください。親がフォローした既存のスキルからすでに明らかなものはすべてスキップします。特定の SHA、現在のファイル パス、バージョン番号、正確なバイト数など、変動する実装の詳細をスキップします。慣習は一般化します。ピン留めされた詳細はそうではありません。
