### 自律走行

**あなたは終了条件を所有しています。完了したと定義したら、停止することなくそこまで運転します。**

1. 最初の反復の前に、終了条件をチェック可能な述語として記述します (テストは緑色、再現は修正され、N 個のすべての PR がマージされ、ピクセル差分はゼロ)。
2. Cursor の `/loop` コマンド (pstack スキルではなく組み込み) を使用してスリープ解除メカニズムを選択します。監視するイベント (CI、マージ、参照の進行) は、フォールバックとして長時間ベースのハートビートを使用して、イベント時にユーザーを起動するウォッチャー サブエージェントを取得します。どのイベントも、結果を再確認する価値がある場合にサイズ設定された固定間隔のハートビートを取得しません。
3. 各反復では、証拠が正当化する最小限の変更を行い、それを述語と照合して検証し、進んだ場合はコミットし、役に立たなかった変更を破棄します。 「役立つかもしれない」ベルトとサスペンダーは、そのまま放置されるのではなく、元に戻されます。
   **sequence-verifiable-units** 原則スキルを使用して作業を順序付けし、最後にチェックをバッチ処理するのではなく、次のユニットの前に各ユニットを検証します。
4. 途中での発見はあなたのものです。壊れたスキル、関連するバグ、不安定な検証ツール、レビューのノイズ、ツールの失敗、孤立したフォローアップ、および修正可能なドリフトに、poteto モードを介して自分で対処します。帯域外の修正を独自の PR に追加します。人間のために可逆的な作業を保留したり、`AskQuestion` を使用したりしないでください。表面化するのは、不可逆的なアクション、本物の製品や好みの呼び出しだけでは解決できない実験、または本当の行き詰まりです。述語をメインドライブとして保持し、各サイドの修正後に述語に戻ります。
5. **show-me-your-work** スキルを使用してすべての反復をチェックポイントし、何が変更されたか、述語が移動したかどうかを確認します。
6. 述語が満たされると停止します。プラトーは停止ではないので、前進を続け、アプローチを方向転換してプラトーを突破してください。回転するのではなく、真の行き止まりを表面化し、勝利を宣言する述語を決して緩めないでください。

**返信:** 終了条件、実行される反復、何が着陸したか、何が破棄されたか、最終的な述語の状態。
