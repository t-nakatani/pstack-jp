### ワークツリーとシミュレーターのクリーンアップ

**ディスクとセーフティ ゲートはあなたが所有しています。** マージまたは放棄された git ワークツリーと古い iOS シミュレータをプルーンして、スペースを再利用します。削除は元に戻すことができないため、使用中のものやコミットされていない作業を保持しているものを削除することをあらゆるステップで防止します。

1. スナップショットと監査。 `df -h /` を記録し、`scripts/worktree-audit.sh` を実行します (原理構築レバー)。これは、手動で入力された `myrepo-worktrees/x` が `.cursor/worktrees/myrepo/x` (構造内の原則エンコード レッスン) に存在するパスを見逃すため、`git worktree list` からパスを読み取りますが、手動で入力されることはありません。各ワークツリーをサイズ、経過時間、マージ状態、コミットされていない作業、PR 状態、およびワークツリーにアクセスした最新のチャットによって分類し、バケットを提案します。トランスクリプト スキャンは遅いため、バックグラウンドで実行します。
2. バケットはアドバイスであり、許可ではありません。固定されたアクティブなチャットは、実際の成果物です (原則として機能することを証明する)。ユーザーまたはサイドバーからそのセットを取得し、すべての候補をクロスチェックします。レバーは、ユーザーが固定したワークツリーである `safe` をマークしているため、固定されたセットが優先されます。
3. 削除する前に使用状況を確認してください。 `verify-recent-chat` 行ごと、または疑わしい行ごとに、サブエージェントを扇動してトランスクリプトを読み、チャットが固定されているか進行中であるか、およびどのワークツリーにアクセスしているかを報告します (原則としてコンテキスト ウィンドウをガードし、トランスクリプトはバルクです)。固定されたチャットは、バックグラウンド サブエージェントを介してアリーナ ツリーと再現ツリーを兄弟ワークツリーに生成します。これらは、名前がサイドバーに表示されない場合でも使用されます。
4. 回復不能な損失が発生した場合は一時停止します。 `wip:N` は、N 件の追跡されたコミットされていない編集です。クリーンなワークツリーを削除するとブランチから回復できますが、コミットされていない作業は失われているため、最初に差分を表示して決定を下してください。 `scratch:N` は追跡されていない使い捨てなので、削除しても安全ですが、ファイルに名前を付けます。自治ごとに、クリーンでマージされ、未使用の収益が得られます。 `wip` および使用中の一時停止。
5. 確認されたセットをプルーニングします。パスごとに、`git worktree remove --force <path>`。無視されたビルド アーティファクトでもディレクトリが存続する場合は、`rm -rf`、次に `git worktree prune` になります。ブランチ参照は存続するため、コミットは失われません。 `df -h /` で確認し、再リストします。
6. シミュレーターおよびその他の回収者。通常、シミュレータは次に大きな勝利を収めます。 `xcrun simctl --set testing delete all` (XCTestDevices クローン)、`xcrun simctl delete unavailable`、`xcrun simctl runtime list`、古いランタイムの場合は `runtime delete <id>`。必要に応じてさらに追加: Xcode `DerivedData` および `iOS DeviceSupport`、`~/Library/Application Support/Cursor` (`state.vscdb.backup`、および `snapshots/roots/<root>` (ワークスペースとして開いたフォルダーの名前が付けられた `<root>` がバルーンで表示されます)、パッケージ キャッシュ (pnpm、uv、brew、yarn)。ユーザーが保持すると言っていなかったキャッシュのみをクリアします。

これは、スリップをキャッチするためのコード レビューを行わずにユーザー状態を削除する 1 つの プレイブック であるため、上記のゲートがレビューです。

**返信:** `df -h /` の前後で、領域が再利用され、ワークツリーがプルーニングされ、それぞれの保留理由 (どのチャットで使用中か、コミットされていない作業か) が 1 行で表示されます。
