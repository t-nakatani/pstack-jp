# pstack ガイド

pstack は、エージェントの微細管理を停止すると最もよく機能します。何を望んでいるのか、そしてそれが完了したことをどのように知るのかを説明します。 `/poteto-mode` はプレイブックを選択し、ステップで必要な他のスキルを実行し、証拠を示します。このガイドでは、現実的なプロンプトでその習慣を教えます。

学習内容は次のとおりです。

1. [pstack をセットアップ](./01-setup.md)。プラグインをインストールし、モデルを選択します。
2. [`/poteto-mode` 経由で作業をルーティングします](./02-poteto-mode.md)。目標を与えて、プレイブックを選択するのを見てください。
3. [コードを理解する](./03-understand.md)。読み取り専用の調査を行ってから、編集する前に `/how`、`/why`、`/teach`、および `/recall` を調査します。
4. [変更を設計](./04-design.md)。 `/architect`、`/arena`、`/swarm`、`/interrogate`、コードがシェイプにロックされる前のプロトタイプ、および計画。
5. [変更をビルドしてクリーンアップ](./05-build-and-clean.md)。ビルド プレイブック、`/tdd`、`/unslop`、および `/no-comments`。
6. [確認してリリース](./06-verify-and-ship.md)。実際のアプリでの動作を証明し、`/benchmark-checklist` で数値を精査し、焦点を絞った PR を開いてマージします。
7. [寝ている間に仕事を実行](./07-overnight.md)。トラスト・ビフォア・ループ、夜間契約、監査可能な意思決定ログ、および 1 人のエージェントを超えてスケールするプロジェクトと自動化。
8. [原則名を使用したステアリング](./08-principles.md)。タスク中にエージェントをリダイレクトする 24 の名前。
9. [あなたのものにしましょう](./09-make-it-yours.md)。独自のモード、繰り返されるミスに対する `/correct`、およびスキルの変更をテストする方法。
10. [レシピと落とし穴](./10-recipes-and-pitfalls.md)。コピーするように求められ、間違った場合はスキップします。

初回はページを順番に読んでください。その後、各ページは独立して表示されます。

行き詰まった場合、またはどのスキルが適しているか判断できない場合は、質問を [`/poteto-help`](../../skills/poteto-help/SKILL.md) と入力してください。

```text
/poteto-help which skill should i use to review this branch?
```

応答し、送信するようプロンプトを提示し、応答の元となったスキルまたはガイド ページへのリンクを示します。 pstack の実行には実際のトークンが消費されるため、作業は開始されません。そのため、準備ができたらプロンプトを送信します。入力したときのみ実行されます。

<a id="if-you-only-remember-one-thing"></a>

## 一つだけ覚えているとしたら

エージェントに目標とそれを確認する方法を自分の言葉で伝えます。

```text
/poteto-mode the export writes duplicate rows when a retry lands mid-run. repro first, then fix and verify.
```

プレイブックに名前を付けたり、スキルをリストしたりする必要はありません。 「最初の再現」とチェック可能な結果は、`/poteto-mode` が必要とするルーティング信号のすべてです。これは、バグ修正プレイブックと一致し、ステップを ToDo リストにコピーし、各ステップの起動時に適切なスキルを呼び出します。

次に: [pstack のセットアップ](./01-setup.md)。
